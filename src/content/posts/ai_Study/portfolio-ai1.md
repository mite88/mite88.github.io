## 🏛️ 프로젝트 개요
* **주제:** 2030 '쉬었음' 인구 데이터 분석을 통한 구조적 단절 진단 및 개인 맞춤형 취업 경로 설계
* **목표:** 개인의 책임을 묻는 '노력 부족' 프레임에서 벗어나, 구조적 위험과 개인의 취업 가능성을 분리 진단하는 정책 지원 도구 개발
* **개발 기간:** 2025.12.22 ~ 2026.01.08 (약 3주)
* **역할:** **프로젝트 조장**, 정책 스크리닝 모델 설계, 독립 모델 통합(Merging), API 서버 개발(확인용)

## 🛠 주요 모델링 및 나의 기여

### 1️⃣ 정책 스크리닝 모델 (Policy Screening Model) - **주도적 수행**
* **철학:** 개인의 노력이 아닌 성별, 지역, 학력 등 변경 불가능한 **구조적 위치**를 기반으로 정책 대상자를 1차 선별합니다. 
* **구조:** '환경 위험(GBDT)'과 '개인 취업확률(GBDT+Calibration)'을 결합한 **4사분면 정책 매트릭스**를 고안했습니다. 
    * **고착형 단절 위험군:** 환경 위험이 높고 취업 확률이 낮은 집단으로 최우선 정책 개입 대상으로 분류합니다. 
* **성과:** 무작위 지원 대비 **2.58배 높은 타겟팅 효율(Lift)**을 입증하여 행정 예산 누수를 방지하는 근거를 마련했습니다. 

### 2️⃣ 이직 성공 예측 모델 (CatBoost + DiCE)
* **목적:** 현재 조건에서의 이직 성공률을 예측하고, 실패 시 '무엇을 바꿔야 성공하는지' 가이드를 제공합니다.
* **기술 스택:** 범주형 변수 처리에 강한 **CatBoost**와 반사실적 설명(Counterfactual) 알고리즘인 **DiCE**를 연동했습니다. 
* **특징:** 성별, 나이 등 바꿀 수 없는 변수(Immutable)는 고정하고, 직업교육이나 구직 활동 등 **실행 가능한 변수(Actionable)**만 변경하여 현실적인 가이드를 제시합니다. 

### 3️⃣ 모델 통합 및 API 서버 구축 - **주도적 수행**
* **PID 기반 병합:** 서로 다른 3개 모델의 결과값을 PID(개인 식별 키) 기준으로 통합하여 다각적 리포트를 생성하는 파이프라인을 구축했습니다. 
* **통합 진단 API:** Flask를 사용하여 개인의 페르소나 정보를 입력받으면 정책 진단, 이직 성공 확률, 행동 권고를 한 번에 응답하는 시스템을 개발했습니다.
