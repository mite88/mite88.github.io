### 1️⃣ 종로 뉴미디어 플랫폼 구축 (SI)
* **수행 기간:** 2025.04.10 ~ 2025.09.25
* **발주처:** 종로구청 / 종로문화재단
* **핵심 성과:** * **콘텐츠 아카이빙:** 종로구 내 방대한 문화/예술 정보를 체계적으로 관리하는 통합 플랫폼 구축

* **Tech Stack:** Java, **eGovFrame**, MySQL, JSP, Map API (GIS)

## 🚀 기술적 총평
* **Modernization:** 노후 시스템을 최신 Java 스택으로 전환하여 시스템 안정성과 유지보수성을 극대화했습니다.
* **Automation:** 반복적인 관리 업무와 정보 전달 과정을 자동화 로직(SMS/Batch)으로 대체하여 운영 효율을 높였습니다.
* **AI Serving:** R&D 과제를 통해 BERT 등 최신 AI 모델을 실무 웹 서비스에 안착시키는 파이프라인 구축 역량을 확보했습니다.
