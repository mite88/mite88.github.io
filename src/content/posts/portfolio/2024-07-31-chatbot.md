## 🏛️ 프로젝트 개요
* **프로젝트명:** 중소기업 기술혁신 개발사업 (시장대응형)
* **수행 기간:** 2022.09.01 ~ 2024.07.31
* **소속:** 와우커뮤니케이션(주) / 연구원
* **핵심 과제:**
    1. **시스템 현대화:** PHP 레거시 → **Spring Boot** 차세대 전환 및 RESTful API 설계
    2. **지능형 챗봇 고도화:** 일반형 챗봇에서 **멀티도메인(Multi-Domain) BERT** 모델로 확장 및 연동
    3. **데이터 보안 및 자동화:** AI 인증 모듈 통합 및 PDF 보고서 자동 생성 기술 개발

---

## 🛠️ System Architecture & Tech Stack

* **Core:** Java 17, Spring Boot, JPA, eGovFrame
* **AI & NLP:** **BERT (Multi-Domain Classification)**, TensorFlow/PyTorch Serving
* **Interface:** REST API, JSON 기반 이기종 시스템 통신
* **Security:** AI 기반 사용자 인증 시스템 연동

> **[핵심 기술: 멀티도메인 챗봇 구조]**
>
> 1. **User Query** (자연어 입력)
> 2. ⬇️ **Domain Classifier** (질문의 범주 판단: 기술지원 / 일반상담 / 제품문의 등)
> 3. ⬇️ **BERT Task Model** (해당 도메인별 최적화된 답변 추론)
> 4. ⬇️ **Response Generator** (최종 결과 전달)

## 💻 주요 연구개발(R&D) 내용

### 1. 멀티도메인(Multi-Domain) BERT 챗봇 구축
**"단일 목적 챗봇에서 다각도 응대 가능한 지능형 엔진으로 진화"**
* **도메인 확장:** 기존의 단순 질의응답 구조를 탈피하여, 여러 비즈니스 영역을 구분해 대응하는 **멀티도메인 분류 체계** 연동
* **Serving API 개발:** Java 백엔드 환경에서 Python 기반의 BERT 모델을 실시간 호출하기 위한 고성능 인터페이스 구축
* **데이터 전처리 고도화:** 각 도메인별 특수 용어 및 문맥을 모델이 정확히 이해할 수 있도록 학습 데이터 정제 및 파이프라인 최적화

### 2. 레거시 시스템 마이그레이션 (PHP → Spring Boot)
**"시스템 안정성 및 확장성 확보"**
* 노후화된 PHP 기반의 모놀리식 구조를 분석하여 **Spring Boot 기반의 서비스 지향 아키텍처**로 재구축
* 복잡하게 얽힌 비즈니스 로직을 리팩토링하여 데이터 무결성을 확보하고 시스템 유지보수 효율성 극대화

### 3. AI 인증 연동 및 문서 자동화 시스템
* **AI 인증 통합:** 보안 강화를 위해 AI 기술이 적용된 사용자 인증 모듈을 시스템 전반에 결합 구현
* **문서 가공 모듈:** 시스템 내 데이터를 활용하여 표준화된 PDF 보고서를 실시간으로 생성 및 가공하는 자동화 기술 개발

## 🚀 트러블 슈팅 및 성과
* **도메인 간 간섭 해결:** 여러 도메인이 섞여 있을 때 발생하는 의도 오분류 문제를 해결하기 위해 분류 임계값(Threshold) 최적화 로직 적용
* **시스템 통합 성과:** 10년 이상 된 레거시 시스템을 성공적으로 전환함과 동시에 최신 AI 기술을 실무 서비스에 안착시킴
* **기술적 스펙트럼:** **Full-Stack 개발 역량**에 **AI 모델 서빙(Serving)** 기술을 더해 지능형 플랫폼 개발 전문가로 성장
